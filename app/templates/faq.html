Frequently asked questions

Everything you need to know about splanly. Can't find an answer? Contact us.

What is splanly?
splanly is a resource planning platform built specifically for chartered accountant firms. It helps you manage team allocations, track engagements, prevent over-booking, and monitor bench utilization — all in one place.
How does the free trial work?
When you create a new firm, you get a 14-day free trial with full access to all features. No credit card required. After the trial, you can activate a license key to continue using splanly.
Can I import my existing team data?
Yes. splanly supports bulk CSV upload for team members. Go to Team Members → Bulk Upload, and upload a CSV with your team data. The system validates each row and reports any errors.
How does over-allocation prevention work?
When you assign someone to an engagement, splanly automatically checks their existing allocations for overlapping dates. If the total would exceed 100%, the assignment is blocked. It also checks for conflicts with approved leave.
What user roles are available?
splanly has four technical roles: Super Admin (platform-level), Admin (full firm management), Moderator (staffing operations), and Viewer (read-only). Roles are assigned per-firm, so a user can have different roles in different firms.
Is my data secure?
Yes. splanly uses industry-standard security: bcrypt password hashing, TOTP two-factor authentication, CSRF protection, session-based auth with secure cookies, and Microsoft 365 SSO integration. All data is stored in encrypted PostgreSQL databases.
Can I use splanly on mobile?
splanly is a web application that works on any device with a browser. The interface is responsive and adapts to mobile screens, though the desktop experience is optimized for the weekly planner grid view.
